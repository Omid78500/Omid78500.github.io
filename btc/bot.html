⚙️ راه‌اندازی (یک بار)

  1. در app.alpaca.markets وارد شو و مطمئن شو حساب Paper (دمو) انتخاب شده. در صفحه اصلی، بخش API Keys، دکمه Generate New Keys را بزن. دو کلید می‌دهد: Key و Secret (Secret فقط یک بار نشان داده می‌شود).
  2. در Safari این صفحه را باز کن: GitHub → New secret
  3. Name: ALPACA_KEY_ID و در Secret همان Key را بگذار → Add secret.
  4. دوباره New secret: Name: ALPACA_SECRET_KEY و در Secret همان Secret را بگذار → Add secret.
  5. تمام. ربات حداکثر ۵ دقیقه بعد شروع می‌کند. کلیدها را هیچ‌وقت در چت یا جای دیگر نفرست.
